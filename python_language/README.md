## pip
- python의 패키지 설치 프로그램
- 스타일패키지(라이브러리) 설치 관리 도구

### 크롤링이란
```
크롤링(crawling)은 웹페이지를 그대로 가져와서 거기서 데이터를 추출해 내는 행위

+ 크롤링과 스크레이핑(scraping)은 실질적인 차이는 없지만, 일반적으로 스크래핑은 하나의 페이지를 수정하는 것이며, 크롤링은 동적으로 웹페이지를 돌아다니면서 수집하는 것을 말한다.
```

## selenium이란?
```
웹 에플리케이션 테스트를 위한 포터블 프레임워크이다.
웹 상에서 정적인 페이지를 탐색하는데 사용하던 beautifusoop같은 패키지가 하지 못하는 동적인 크롤링을 지원한다

 * 동적인 크롤링: url 상에는 아무런 변화 없이 동작하는 웹 페이지에 대한 크롤링
```

 ## 크롤링
 - 정적 크롤링: Beautiful Soup
 - 동적 크롤링: selenium(페이지 이동하여 크롤링, 시간이 더 걸림)
    - pip install selenium

## 판다스(pandas)
- 데이터 조작 및 분석용 라이브러리
- 1차원(Series), 2차원(DataFrame) 데이터를 다룰 수 있으며, json, csv, xls등 다양한 타입과 호환

    Series
    - 배열과 비슷한 구조
    - 인덱스를 임의로 지정할 수 있음
    - 인덱스 기준으로 연산도 가능

    DataFrame
    - 행(row), 열(colmu)로 이루어진 2차원 구조
    - db의 테이블과 비슷한 형태
